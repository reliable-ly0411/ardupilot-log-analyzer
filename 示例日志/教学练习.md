# QuadPlane 教学日志练习

这是人工合成 DataFlash 日志，固件字符串和传感器数据仅用于演示，不能当作真实试飞结论。

先打开日志，再进入“分析引导”。按课程打开推荐曲线，对照下列已知区间验证读图方法。时间相对首次解锁。

| 练习 | 已知证据 | 相对解锁区间 |
| --- | --- | --- |
| 动力余量 | 四路 PWM 输出接近配置上限 | T+0:55 至 T+1:00 |
| 姿态跟踪 | 横滚目标与实际偏差约 23° | T+1:15 至 T+1:18 |
| GPS | 主 GPS Status=2、卫星数=6；备用 GPS 保持正常 | T+1:20 至 T+1:24 |
| EKF | 主 EKF 核心 SV=1.6；备用核心较低 | T+1:38 至 T+1:42 |
| 飞控消息 | 保护触发、内部错误及后续解除 | T+1:40 起 |
| 短时振动 | VibeX=85 m/s²，同时 Clip0 增加 4 | T+1:51.100 |
| 转换 | 固定翼模式中 Trn=0、Ast=1 持续 14 秒，超时设置 10 秒 | T+2:25 至 T+2:39 |
| 电池 | 20.4 V，低于日志 21 V 严重低电筛查门限 | T+2:50 至 T+2:55 |
| 供电 | Vcc=4.3 V | T+3:00 至 T+3:01 |

思考：哪些数据只表示控制命令？哪些证据可以确认测量异常？哪些还不足以确定硬件故障？把答案和下一步验证计划写入“试飞记录”。

日志在解锁之前还包含姿态误差和历史削波计数，用于验证软件不会把这些记成本次飞行新增故障。
