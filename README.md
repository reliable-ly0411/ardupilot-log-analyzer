# 飞析 · ArduPilot 日志分析器

面向 **QuadPlane 垂直起降固定翼** 试飞复盘的 Windows 离线日志分析工作台。它把“找异常、定位故障时段、核对证据、记录结论”串成一条可复查流程，并提供分析引导，帮助刚开始读 DataFlash 日志的工程师建立判断路径。

## 主要能力

- 自动识别飞控固件、机型、QuadPlane 布局和飞行窗口。
- 风险诊断带有起止时间、触发门限、极值、持续时间、原始样本数和证据来源，可双击跳到对应曲线。
- 保留原始数值采样，显示阶段才按屏幕列压缩；GPS 实例和 EKF 核心分开处理。
- 覆盖姿态跟踪、振动与新增削波、EKF 创新检验、GPS、按日志门限筛查电池低压、飞控供电、旋翼输出余量、前转换空速等待和飞控事件。
- 缺少证据会标为“未判断”，不会把缺字段当成正常。
- 九个“分析引导”主题，说明先看什么、怎样判断、下一步如何交叉验证，并能打开推荐曲线。
- 试飞记录自动保存；支持 CSV、PNG、HTML 和 PDF 复盘报告。

## 快速开始

1. 从 [Releases](../../releases) 下载运行包，或按下方步骤从源码构建。
2. 双击 `飞析.exe`，点击左下角“打开教学示例”。
3. 进入“分析引导”，选择“姿态跟踪与 PID”，阅读课程后点击“打开本课推荐曲线”。
4. 回到“风险诊断”双击一项异常，先看前后 15 秒，再缩小到 1–3 秒。
5. 在“试飞记录”写下现象、证据、已验证结论、待验证假设和下一步动作。

教学日志和练习说明在 [`示例日志`](示例日志)；完整操作说明在 [`使用说明.md`](使用说明.md)。

## 从源码构建

需要 Qt 5.15.2 MinGW 8.1 和 Python 3。默认路径是 `F:\Qt.15.2\mingw81_64` 与 `F:\Qt\Tools\mingw810_64`，也可以传入 `-QtRoot` 和 `-MinGWRoot`：

```powershell
powershell -ExecutionPolicy Bypass -File .\构建.ps1 -Verify
```

`-Verify` 会生成可重复的正常、异常和缺字段样例，并运行回归检查。源码设计说明在 [`源码/README.md`](源码/README.md)。

## 项目范围

这是有明确门限的规则筛查工具，不替代飞控手册、适航要求、硬件检查和试飞安全评审。它不会仅凭日志确定硬件故障根因；FFT、气动失速判定、多架次自动拆分尚未实现。真实机型需要按固件版本、输出协议、传感器安装和试验工况复核门限。

转换检查已对照 ArduPilot Plane 4.5/4.6 的 QTUN 状态定义：普通 QuadPlane 中 `Trn=0` 是空速等待、`Trn=1` 是计时阶段、`Trn=2` 是完成；缺少版本、机型或必要字段时不会猜测。
